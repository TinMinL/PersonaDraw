浅拷贝只新建最外层容器，里面的元素仍引用原来的对象；深拷贝会递归复制内部对象。**区别要看嵌套对象是否共享，不能只看最外面的列表是不是新的。** 本龙先拆开两层给你看，别让一个 `copy` 把你哄过去。

下面按代码逐步推演，没有实际执行：

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.copy(a)       # 浅拷贝，也可写 a.copy() 或 a[:]
c = copy.deepcopy(a)   # 深拷贝

print(a is b)          # False
print(a[0] is b[0])    # True
print(a[0] is c[0])    # False

b[0].append(9)
print(a)              # [[1, 2, 9], [3, 4]]
print(b)              # [[1, 2, 9], [3, 4]]
print(c)              # [[1, 2], [3, 4]]

b[1] = [7, 8]
print(a)              # [[1, 2, 9], [3, 4]]
print(b)              # [[1, 2, 9], [7, 8]]
```

先看前三个输出：`a`、`b` 是不同的外层列表，但 `a[0]`、`b[0]` 指向同一个内层列表。`c` 的内层列表则已经复制出来，所以与原列表分开了。

接着看 `append`：它修改的是那个共享的内层列表。因此，从 `a` 和 `b` 两边看，都多了一个 `9`；`c` 不受影响。（外壳换新，里面还合用；浅拷贝省的就是这一份工。）

最后这句值得盯紧：`b[1] = [7, 8]` 是**替换 `b` 的一个元素引用**，并没有修改原先的 `[3, 4]`。外层已经独立，所以 `a[1]` 保持原样。别把“修改内层对象”和“替换外层元素”混成一件事，很多困惑就卡在这儿。

怎么选，我会先问你准备改哪一层：

- 只给外层增删元素、排序，或者里面都是整数、字符串等不可变对象，通常用浅拷贝就够了。
- 要修改嵌套列表、字典，同时保留原数据，考虑 `deepcopy`；它通常更耗时间和内存，别见到“深”字就觉得更高级。
- 只需修改少数内层对象，也可以只复制那些分支，但要确认没有漏掉仍会被修改的共享对象。

再拦住三个常见误解：`b = a` 根本没有复制，只是多了一个名字；浅拷贝不是“所有修改都会联动”，是否联动取决于改到了哪个对象；深拷贝也不是“所有东西都必须重建”，不可变对象可能复用，文件等资源不能当普通数据复制。

还有个细节：`deepcopy` 通常会保留原结构内部的共享关系。原来两个位置指向同一子列表，复制后通常也指向同一个新子列表。它负责复制对象关系，可没承诺把每条引用都拆散。
