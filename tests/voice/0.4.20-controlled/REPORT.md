## 交付完整性缺陷
W 初稿及最终稿中的两条激活命令含 U+0007 BEL。执行者确认是 Python 普通字符串把反斜线 a 转义；不是 CMD 语法，也不能归因于人设规则。详见 W.transport-note.md。原样保留，不将修正后版本替换原证据。

新增可复用检查器 validate_outputs.py；实际执行检查 V/W/X/Y，返回1，准确标记W失败；其他三份通过字符、结构与长度检查。该检查不替代命令语义审核或真实Windows执行。

运行方式：
```sh
python validate_outputs.py V.md W.md X.md Y.md
```

## 结论与处理
V（精简）/W（正式）在人设上接近：W中段略连续，V吐槽更利落；X（正式）对Y（精简）有小幅优势。没有跨角色一致收益。Y还把示例requests扩展成用户工具一定含网络请求功能的表述，应保留为题设忠实度缺口，而不是已验证用户需求。
不发布候选，正式版本保持0.4.20。本轮与前两轮累计证据不足以支持将该精简候选作为修复；暂时停止对同一候选追加同类试验。保存候选供参考不代表通过，也不证明长规则一定更好。后续若恢复表达修改，须采用不同、明确的假设并检验真实中段失败案例；本轮不预告修复完成。
