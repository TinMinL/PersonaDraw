# W 文件写入缺陷

主任务字节检查发现 W.md 两处 U+0007（偏移 219、1145），都位于激活命令中。W.draft.md 与 W.md 保持原样，不替换成修正后的答案来掩盖失败。

执行者报告：通过 exec_command 运行 Python heredoc，全文置于非 raw 的普通三引号字符串中；路径中的 `\a` 被 Python 解析为 BEL，形成 `.venv\Scripts` + BEL + `ctivate.bat`。后续长度修订从初稿读取，仅替换解释段，因此损坏保留。不是 CMD 或源资料行为，也无证据证明人设规则导致。

本缺陷属于保存产物的命令完整性失败。风格仍可单独评价，但此样本不可视作可直接执行的合格教程。后续保存包含反斜线的正文应使用结构化写入或 raw 字符串；validate_outputs.py 检查控制字符、六节结构和汉字数。检查器不能证明命令语义正确或替代 Windows 实测。
