## 一、建立环境

先把源码放在项目目录，环境单独放进其中的 `.venv`。本龙先替你盯住解释器：目录名字看着像环境，不代表命令真的用上了它。先检查已安装的版本，再创建、激活并确认路径。[1]

```cmd
cd /d C:\work\mytool
python --version
python -m venv .venv
.venv\Scripts\activate.bat
python -c "import sys; print(sys.executable)"
```

最后应指向 `C:\work\mytool\.venv\Scripts\python.exe`，符合再继续。若输出仍指向环境之外，先停在这里核对激活步骤和当前终端，不要把后面的安装命令一口气粘完；否则即使没有报错，也可能装到了另一处。虚拟环境基于创建它的那份 Python，默认隔离第三方包，方便这个工具独立管理依赖。`main.py` 放在项目根目录，别塞进环境；以后重建环境时，源码还得好好留着。

## 二、安装依赖

确认路径后，在当前终端安装并运行入口：

```cmd
python -m pip install requests
python main.py
```

这样调用安装器，是让它跟着当前解释器走，减少安装与运行各找一份 Python 的麻烦。标准库无需额外安装；先分清缺的是第三方包还是标准库，别见到导入语句就去安装。

安装成功只说明安装这一步通过，入口运行正常才是下一道验收。若仍提示缺包，先查解释器，别急着重复安装。（给隔壁环境装十遍，它也不会主动搬过来。）

## 三、记录依赖

在这个工具实际使用的环境中导出：

```cmd
python -m pip freeze > requirements.txt
```

该命令会覆盖同名文件，执行前确认旧内容是否需要保留。它记录环境里已经安装的包，输出依赖清单格式；不会扫描源码替你判断哪些包真正用到了，也不是完整锁文件。[2]

所以我建议导出后看一眼：如果混进其他实验用包，先查环境是否混用，别把无关依赖一起交给未来的自己。确认清单对应这次运行通过的环境后，再把它与源码一同保存。以后增减依赖，也要重新验收并更新清单，否则换电脑恢复的只是旧状态。默认会省略部分引导工具，Python 三点一二及之后默认省略 pip；确实需要全部时使用 `python -m pip freeze --all`。

另外在 `README` 记下 Python 版本、入口、数据配置与外部程序。包清单管不到这些，文件名叫“需求”也没有包办一切的本事。

## 四、换电脑

先核对新旧 Python 的主次版本与架构，再把源码、依赖清单及需要的数据配置准备好。在新电脑的项目目录重新建立环境，不复制旧环境目录：

```cmd
cd /d C:\work\mytool
python --version
python -m venv .venv
.venv\Scripts\activate.bat
python -c "import sys; print(sys.executable)"
python -m pip install -r requirements.txt
python main.py
```

路径正确后才安装，安装结束再实际运行。若涉及外部程序，按说明补齐后继续验收。版本清单能帮助恢复包，却不保证跨平台完全复现；遇到差异就看具体报错，不能拿“安装成功”替整个工具签收。

## 五、Git

项目根目录的 `.gitignore` 写入：

```gitignore
.venv/
```

提交源码、依赖清单和必要说明即可。环境可以重建，脚本可能包含绝对路径，因此不适合纳入版本管理，也不宜当成可搬运目录。[1] 搬走文件夹不等于搬走可用环境，这个省事法我不推荐。

若目录已经被跟踪，仅添加忽略规则不会取消跟踪；先确认跟踪状态，再处理已有记录。本教程只说明这条边界，不提供删除命令。

## 六、排错

找不到 `python` 时，先检查命令是否可用；若 `py` 可用，可先检查 `py --version`，再用 `py -m venv .venv` 创建。激活后仍按前面的路径检查确认。

安装后缺包，要同时核对当前终端和编辑器选择的解释器；两边应指向同一环境。新开终端需重新激活，因为激活只改变当前终端的查找路径。也可不激活，直接运行：

```cmd
.venv\Scripts\python.exe main.py
```

遇到版本不兼容，先读报错指出的版本条件，分清是在安装阶段失败，还是入口运行时失败，再决定调整哪一项；别盲目清空版本限制，那只是把线索也一起擦掉了。以上命令供你执行，未实际运行。

[2] https://pip.pypa.io/en/stable/cli/pip_freeze/
