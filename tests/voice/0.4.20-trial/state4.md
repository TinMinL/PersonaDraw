外键是表中用于引用另一张表（也可以是本表）主键或唯一键的字段或字段组合。例如，选课表中的“学生学号”引用学生表的“学号”，用于表示这条选课记录属于哪个学生；启用外键约束后，可以防止记录引用不存在的学生。

三个人开发时，建议通过 Git 共享这些文件：

- 源代码和依赖清单，保证大家运行的是同一套程序。
- 建表脚本及数据库迁移脚本，统一表结构和后续变更。
- 初始化或测试数据，例如 JSON、CSV 或 SQL 文件，保证数据可重复生成。
- 初始化、重置数据库的脚本，以及运行说明和不含密码的配置示例。

各自的运行数据库 `.db` 通常加入 `.gitignore`，由上述脚本在本地生成，避免提交和合并运行过程中产生的数据差异。如果需要统一演示数据，可以指定一份只读基准数据库作为发布资源，但不要让三个人分别修改后再合并。SQLite 项目还应在每个数据库连接上确认启用外键检查，例如执行 `PRAGMA foreign_keys = ON;`。
