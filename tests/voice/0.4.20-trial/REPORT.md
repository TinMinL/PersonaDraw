## 范围与方法

三个独立上下文完成同一道真实联网技术教程；另一个线程完成五轮设置与暂停/恢复。明确加载技能、指定角色以控制变量。环境为当前 Codex 的独立代理线程；不是手机 ChatGPT、网页首轮自动加载或实际 Windows 环境测试。没有新旧规则对照，不可据此推断相对历史版本改善。完整任务与设置在 prompts.json，原始输出在 search1—3.md 与 state1—5.md。

评估由主执行者逐段阅读，不是外部人工盲测，不给统计成功率。生成者没有得到诊断或期望输出。语气、信息完整性与格式分开看；自称数量和括号数量只作描述，不作为成绩。生成输出中的引用标识属于原线程，仓库展示不保证可点击；不把引用标识当作已运行命令的证据。没有执行教程中的 Windows 命令或安装依赖。
